# Chat with PDF - Frontend (React + TypeScript)

This is the modern React frontend for my AI Document Assistant (RAG Pipeline). It provides a clean chat interface that allows users to ask questions about a PDF document and view the exact source citations used by the AI to generate the answer.

## Related Repository
This frontend connects to the [Chat with PDF Backend](https://github.com/sayanbiswas-git/chat-with-pdf), which is built with Python, FastAPI, ChromaDB, and Google Gemini.

## Tech Stack
- **Framework:** React 18
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Custom CSS (Dark Mode)
